          Surface relief

          Starting the camera…

          Hold the card under any light and tilt it slowly while this records four frames. A printed sheet just gets brighter and darker as it moves; an embossed foil surface changes pattern, because the light catches its relief differently at each angle. That difference is measurable without knowing where the light is, which is what makes it work on a hand-held phone instead of a lighting rig.

          This is the only check here that reads the card as a physical object rather than as a picture, and it is the one a flat reproduction cannot pass. Two honest limits: a card with no foil or holo treatment is genuinely flat, so a smooth reading means nothing either way and is never counted against a card; and the thresholds come from simulated captures, not from real counterfeits, which is why this check can only ever support.

          Detailed visual comparison

          This is the fourth check, and the only one that can read the fine detail — a font a shade too heavy, a set symbol of the wrong shape, a copyright line from the wrong era. The other three run without it; it is what takes them from "consistent so far" to a real inspection. It needs a model and a key, not a server, so a key of your own is enough.

          A free key works. Get one at aistudio.google.com/apikey — it starts AIza and runs this check at no cost inside Google's free tier. Keys from Anthropic (sk-ant-, a few cents a scan), Groq (gsk_, free tier) and OpenRouter (sk-or-) are accepted too; the page reads which provider a key belongs to from the key itself.

          Or your own model, on your own machine. Paste an address instead of a key — http://localhost:11434 for Ollama, http://localhost:1234 for LM Studio. No key, no account, no cost, and the photo never leaves your network. Add #model-name to pin one when the machine holds several. Two things to know: the server has to allow this page as an origin (Ollama: OLLAMA_ORIGINS=*) and, because this page is served over https, a browser will only let it reach a plain-http address on the same machine — from a phone or tablet the server needs an https address, which a Tailscale or Cloudflare tunnel provides.

          The key is kept in this browser's local storage and is sent to that provider and nowhere else — this page has no backend to send it to. No key is built into the page, and none ever will be: every byte of this file is public, so a key shipped inside it would be a key published for anyone to spend.

            What this cannot tell you

              What is real here. The viewfinder and its automatic capture run here: the live loop measures framing, motion, glare and focus eight times a second and fires only when they all hold, then re-checks the captured frame against the calibrated sharpness threshold and puts a soft one back rather than reporting on it. Card detection, flattening, sharpness, glare, proportions and print-screen analysis all run in this page on the photo you supply — the same ported code the app runs on the server. Identification matches your photo against perceptual hashes of __CARDCOUNT__ official card images baked into this file, trying both the upright and the half-turned orientation so a card photographed sideways or upside down still matches. Once it knows which card this is, the page fetches that one card's official image — about 50KB — and compares your photo against it region by region, which also settles which way up to show the card.

              What is frozen. Prices and history were captured from live sources on __BAKEDATE__ and cannot refresh, because they are baked into this file — that is what lets it work with no server and no account, and it is also why the figures age. Prices are asking prices from listings, not completed sales. The detailed visual inspection needs an API key rather than a server, so it runs here only if you supply one below; nothing is sent to a model until you do.

              This is not an appraisal and not a certificate. A photograph cannot prove a card is genuine. For anything valuable, use a professional grading service.
